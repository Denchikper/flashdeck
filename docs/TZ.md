# Flashdeck — техническое задание

## Идея

Десктопное приложение для запоминания слов (и любых пар «вопрос — ответ») по карточкам.
Пользователь собирает колоды, добавляет карточки и тренируется. Приложение запоминает,
какие карточки даются хуже, и показывает их чаще.

## Функции

### Колоды
- список колод на главном экране: название, количество карточек, процент выученных;
- создание, переименование, удаление (с подтверждением);
- импорт колоды из CSV и экспорт в CSV.

### Карточки
- поля: слово, перевод, пример использования, картинка (необязательно);
- добавление, редактирование, удаление;
- поиск по колоде;
- у каждой карточки есть уровень изученности (0–5), который меняется после тренировок.

### Тренировка
- настройки перед стартом: количество карточек, направление (слово → перевод / перевод → слово),
  режим (ввод ответа / выбор из 4 вариантов), перемешивание;
- карточки с низким уровнем попадают в тренировку первыми;
- после ответа показывается правильный вариант и картинка;
- в конце — итог: сколько верно, список ошибок, кнопка «повторить ошибки».

### Статистика
- график точности по последним тренировкам;
- самые сложные карточки;
- общее: сколько тренировок, сколько карточек выучено.

### Прочее
- сохранение итогов тренировки в текстовый файл;
- окно «О программе».

## Технологии

| Требование | Как реализовано |
|---|---|
| requirements.txt | PyQt6, PyInstaller |
| Несколько форм | главное окно (QMainWindow), редактор колоды, карточка, настройки тренировки, тренировка, статистика, о программе (QDialog / QWidget) |
| Qt Designer | формы карточки, настроек тренировки и «О программе» — .ui-файлы, загружаются через uic.loadUi |
| Изученные виджеты | QLabel, QPushButton, QLineEdit, QPlainTextEdit, QCheckBox, QRadioButton + QButtonGroup, QComboBox, QSpinBox, QListWidget, QTableWidget |
| Дополнительные виджеты | QProgressBar, QSlider, QLCDNumber, QTabWidget, QStatusBar, меню и панель инструментов, свой виджет графика на QPainter |
| Стандартные диалоги | QMessageBox, QFileDialog, QInputDialog |
| Картинки | QPixmap на карточках, иконка приложения и кнопок |
| Файлы txt / csv | импорт/экспорт колод в CSV, отчёт о тренировке в TXT |
| БД (SQLite) | таблицы decks, cards, sessions, answers; чтение, запись, изменение, удаление |
| exe | сборка PyInstaller в один файл |

## Структура БД

- **decks** — id, name, created_at
- **cards** — id, deck_id, word, translation, example, image_path, level
- **sessions** — id, deck_id, started_at, total, correct
- **answers** — id, session_id, card_id, is_correct

        training_setup.py   настройки тренировки
        training_window.py  тренировка
        stats_window.py     статистика
        about_dialog.py     о программе
        chart_widget.py     график точности (QPainter)
    ui/forms/           .ui-файлы из Qt Designer
assets/                 иконка, пример колоды
tests/                  тесты логики, БД и CSV
